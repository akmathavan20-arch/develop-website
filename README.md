# Dream Learn Education Platform

Production-style starter for **Dream Learn** with dark/premium UI and role-based learning workflows.

## Implemented in this version
- Home page with dark theme branding.
- Authentication APIs: register/login.
- Roles: `student`, `faculty`, `admin`.
- Student dashboard API and Admin users API.
- AI APIs (starter mock endpoints): chatbot, story generator, quiz generator.
- Curriculum API preloaded with Nursery to Grade 5 subjects.
- Database tables: Users, Courses, Payments, Progress, Content.
- Payment states supported in schema: Active, Pending, Expired.

## Run
```bash
npm install
npm run start
```
Open: `http://localhost:3000`
